# Documentation

`Team_Currents_Final_Document.pdf` is the final engineering documentation supplied for the Nationals configuration.

It documents:

- team/project development
- mechanical evolution
- final 4WD drivetrain and mechanical differential
- CAD/PLA architecture
- steering system
- motor selection
- power architecture and measured voltages
- two-camera perception system
- HSV/LAB computer vision
- navigation and marker counting
- obstacle avoidance
- rear-camera parking
- MPU6050 heading feedback
- testing methodology
- Open Challenge results
- Obstacle Challenge results
- engineering risks and limitations
- reproducibility requirements
- repository organization
- final system architecture
